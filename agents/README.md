# agents/

The canonical source of the agent layer: the skills, subagents, commands and hooks that let a coding agent run the RACE. Edit files here. `plugins/the-race/` is generated from this directory and must not be edited by hand.

## Contract

```
agents/
  plugin.json                 Plugin metadata: name, version, description, author, license, keywords, homepage, repository
  skills/<name>/SKILL.md      Skill. Frontmatter `name` (equal to the folder) and `description`, then the body.
  skills/<name>/...           Optional supporting files, copied as they are
  subagents/<name>.md         Subagent. Frontmatter `name` (equal to the file name) and `description`, then the prompt
  commands/<name>.md          Slash command. Frontmatter `description`, then the prompt
  hooks/hooks.json            Optional. Hook configuration, with or without the outer {"hooks": ...} wrapper
  hooks/<script>              Hook scripts, copied as they are
```

Frontmatter is flat `key: value` lines. `skills/` needs at least one skill; the other folders are optional. A hook command refers to its script as `${CLAUDE_PLUGIN_ROOT}/hooks/<script>`, and the generator fails if that script is not in `agents/hooks/`.

## Generated tree

`npm run generate` writes:

```
.claude-plugin/marketplace.json            Local marketplace listing the plugin with a relative source
plugins/the-race/
  .claude-plugin/plugin.json               From agents/plugin.json
  .mcp.json                                Declares the `the-race` MCP server (node packages/mcp/dist/main.js)
  skills/<name>/SKILL.md                   From agents/skills/
  agents/<name>.md                         From agents/subagents/ (Claude Code calls them `agents`)
  commands/<name>.md                       From agents/commands/
  hooks/hooks.json, hooks/<script>         From agents/hooks/, always with the outer {"hooks": ...} wrapper
  GENERATED.md                             Marker: this tree is generated
```

Markdown files carry a `Generated by` comment right after the frontmatter. `npm run lint:generated` regenerates in memory and fails, listing the stale files, when the committed tree differs; CI runs it.

## Try it locally

Build the server (`npm run build`), then in Claude Code: `/plugin marketplace add <path to this repository>` and `/plugin install the-race@the-race`. The MCP server path is relative to the plugin root, so the plugin must be loaded from this checkout.
