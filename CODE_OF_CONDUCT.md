# Code of conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/). The short form:

- Be respectful and welcoming. Disagree with ideas, not with people.
- No harassment, discrimination, personal attacks, or publishing someone's private information.
- Assume good faith, give and accept feedback gracefully, and keep to the topic.

This applies to issues, pull requests, discussions and any other space where the project is represented.

## Enforcement

Maintainers may edit or remove contributions and restrict participation to protect the community. To report a problem, use [GitHub's private reporting](https://github.com/Klim-101/the-race/security/advisories/new) or message the maintainer through their GitHub profile. Reports are handled privately.
